# Supermaven

**Supermaven** is an AI code completion tool known for its extreme speed and large context window (1 million tokens). It uses a new architecture designed for low latency.

## Key Features
- **Speed**: Claims to be the fastest copilot.
- **Long Context**: 1 million token context window allows it to understand the entire codebase.
- **Low Latency**: Suggestions appear almost instantly.

## Installation
1.  Install the **Supermaven** extension for VS Code (or other supported IDEs).
2.  Sign up/Login at [supermaven.com](https://supermaven.com/).
3.  The extension will automatically start providing completions.

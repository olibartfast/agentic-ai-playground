# Experiments

Runnable agent-framework prototypes belong here. The directory is currently
empty: the earlier `ai-agents-langgraph/` and `a2a-protocol/` examples were
removed on 2026-08-24 rather than modernized, and their history is preserved in
git.

A prototype added here should pin its dependencies, state which model and
endpoint it was run against, and carry a check that can run without a network
call. An unmaintained pinned tree accumulates advisories whether or not the
code is ever executed, which is what removed the previous two.

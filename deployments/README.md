# Deployment targets

Self-hosted inference can run on a personal machine or on rented infrastructure.
These runbooks describe compute placement; model and runtime selection remain
under [`models/`](../models/) and [`serving/self-hosted/`](../serving/self-hosted/).

- [Personal workstation checklist](workstation/)
- [AWS checklist](aws/)
- [RunPod checklist](runpod/)
- [NVIDIA Brev checklist](brev/)

Cloud instructions are provider-neutral where possible. Provider templates
should be added only after their settings are reproducible.

# GitHub Copilot

**GitHub Copilot** is an AI pair programmer that helps you write code faster and with less work. It draws context from comments and code to suggest individual lines and whole functions instantly.

## Key Features
- **Code Completions**: Suggests code as you type.
- **Chat**: Integrated chat interface in VS Code and other IDEs to ask questions, generate code, and refactor.
- **Copilot Workspace**: A task-centric environment to plan and implement changes across multiple files (Preview).
- **CLI Integration**: `gh copilot` for shell command suggestions.

## Installation

### VS Code
1.  Open VS Code.
2.  Go to the Extensions view (`Ctrl+Shift+X`).
3.  Search for "GitHub Copilot".
4.  Install the extension.
5.  Sign in with your GitHub account.

### JetBrains IDEs
1.  Go to Settings/Preferences > Plugins.
2.  Search for "GitHub Copilot".
3.  Install the plugin and restart the IDE.
4.  Sign in via the Tools menu.

## Configuration
- Enable/Disable globally or for specific languages in the status bar.
- Configure keyboard shortcuts for accepting/rejecting suggestions.

# Amazon Q Developer

**Amazon Q Developer** (formerly CodeWhisperer) is a generative AI-powered assistant for software development, optimized for building on AWS but capable of general-purpose coding.

## Key Features
- **IDE Integration**: Available in VS Code, IntelliJ, and AWS Cloud9.
- **Security Scans**: Scans code for security vulnerabilities.
- **AWS Optimization**: Specialized knowledge for AWS SDKs, CDK, and best practices.
- **Feature Development**: Can generate code for full features from a description.
- **Q CLI**: Command line integration for shell completions and natural language translation to commands.

## Installation

### VS Code
1.  Install the **Amazon Q** extension from the Marketplace.
2.  Authenticate using an AWS Builder ID (free for individuals) or AWS IAM Identity Center.

### JetBrains
1.  Install the **AWS Toolkit** plugin.
2.  Sign in to Amazon Q within the toolkit.

## Usage
- **Completions**: Automatic as you type.
- **Chat**: Open the Amazon Q panel to ask questions about your code or AWS resources.
- **Security Scan**: Run scans from the extension menu.

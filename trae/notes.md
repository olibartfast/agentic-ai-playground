# Trae

**Trae** is an adaptive AI IDE developed by ByteDance. It is designed to transform how you code by integrating AI deeply into the development workflow.

## Key Features
- **Adaptive AI**: Learns from your coding patterns.
- **Chat & Edit**: Integrated chat that can perform edits across files.
- **Smart Context**: Understands the project structure and dependencies.

## Installation
1.  Visit the [Trae website](https://www.trae.ai/).
2.  Download the installer for your OS (macOS/Windows).
3.  Install and run.
